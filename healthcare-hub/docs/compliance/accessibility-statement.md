# Accessibility statement – Healthcare Hub (draft)

We want as many people as possible to be able to use Healthcare Hub. The service aims to meet
**WCAG 2.2 level AA** (NFR-03) on the web app and the crew app.

## How we test

- Every status is shown with text and an icon as well as colour.
- Automated checks: axe-core in a real browser on 12 main web screens, with no violations found
  (`accessibility-scan.md`), and component tests that check labels and roles.
- Crew app: large touch targets, labelled controls, no typing needed while moving, and screen
  readers announce statuses.

## Still to do before go-live

- A manual keyboard-only walkthrough of every web journey.
- Screen reader testing: NVDA with Firefox and VoiceOver with Safari, plus TalkBack and VoiceOver
  on the crew app.
- Zoom to 400 % and text spacing checks.
- An external audit if the organisation's commissioner requires one.
