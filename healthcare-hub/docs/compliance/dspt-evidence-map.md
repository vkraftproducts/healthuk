# Data Security and Protection Toolkit – evidence map

Mapped to the ten National Data Guardian standards. _Check against the DSPT version current at
submission (the toolkit is being aligned to the Cyber Assessment Framework for some sectors)._

| NDG standard                 | Evidence in Healthcare Hub                                                                                        | Organisation provides                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 1 Personal confidential data | DPIA draft, ROPA entries, minimisation (no clinical fields), field encryption, restricted policies                | Completed DPIA, privacy notices          |
| 2 Staff responsibilities     | Policy library with acknowledgement by version; critical instructions need explicit confirmation                  | IG and acceptable-use policies           |
| 3 Training                   | Training requirements tracked per role with expiry and verification                                               | Annual data security training records    |
| 4 Managing data access       | RBAC matrix, row-level security, audit of sensitive views and exports, leaver revocation, support access approval | Access reviews                           |
| 5 Process reviews            | Audit programme, action ageing report, management pack                                                            | Board review minutes                     |
| 6 Responding to incidents    | Breach records with the 72-hour ICO clock, event workflow, alerts                                                 | Incident response plan, contacts         |
| 7 Continuity planning        | PITR + geo-redundant backups, restore runbook and drill report, downtime procedure in the crew app                | Business continuity plan, drill sign-off |
| 8 Unsupported systems        | Supported runtimes pinned; dependency scanning; mobile app requires current OS versions                           | Device inventory                         |
| 9 IT protection              | Cyber Essentials evidence, ZAP baseline, penetration test and remediation log, TLS everywhere                     | Network and endpoint protection          |
| 10 Accountable suppliers     | Subprocessor list (DPIA §6), UK hosting                                                                           | Supplier contracts and due diligence     |
