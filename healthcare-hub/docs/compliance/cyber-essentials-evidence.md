# Cyber Essentials – evidence for the cloud service

Cyber Essentials certifies the **organisation**; this maps the five technical controls to evidence
for the Healthcare Hub service in scope. _[Organisation]_ items cover its own devices and accounts.

| Control                    | Healthcare Hub evidence                                                                                                                                                                                                          | Organisation provides                                                                |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Firewalls                  | Azure-managed ingress only (Container Apps HTTPS); Postgres and Storage restricted by firewall rules; no inbound management ports (infra/)                                                                                       | Office and home-working router and device firewall settings                          |
| Secure configuration       | Infrastructure as code (infra/); no default credentials (production refuses development keys and the mock sign-in); security headers and strict CSP; dependencies pinned and scanned (CI)                                        | Device build standard; removal of unused software/accounts                           |
| User access control        | Entra External ID with MFA; least-privilege roles; server-side permission on every endpoint; row-level security; leaver access ends on next call; support access is time-limited and approved; access reviews from the audit log | Joiner/mover/leaver process; admin accounts separate from daily use                  |
| Malware protection         | Uploads land in quarantine, are scanned (Defender for Storage) and type-checked before anyone can download them; unscanned files are never served                                                                                | Anti-malware on staff devices; app stores only on crew phones (managed distribution) |
| Security update management | Dependabot and `pnpm audit` in CI; container base images rebuilt on each release; Azure PaaS patched by the platform                                                                                                             | Supported OS versions and 14-day patching on all staff devices and phones            |
